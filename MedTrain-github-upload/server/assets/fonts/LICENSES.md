Fonts bundled for server-side PDF rendering (embedded directly so Arabic and
Latin text render correctly regardless of what fonts are installed on the
deployment host):

- `Amiri-Regular.ttf`, `Amiri-Bold.ttf` — the Amiri typeface, SIL Open Font
  License 1.1. https://github.com/aliftype/amiri
- `DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` — DejaVu Sans, Bitstream Vera
  License. https://dejavu-fonts.github.io/
